# Installation

See the [current README](README.md#install). The supported alpha requires Python 3.11+ and has no third-party runtime dependencies. Do not use the historical privileged Compose/Kubernetes instructions or launch the removed API/UI entry points.

Docker is needed only for the optional isolated research benchmark. [Research environment setup](docs/SANDBOX.md) lists the exact tools and versions used, isolation checks and reproduction steps. Never install or execute incident samples on your host.
